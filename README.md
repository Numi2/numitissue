# NumiTissue

NumiTissue is an Apple-Silicon-native, multiscale simulator for developing neural tissue. It is designed to couple molecular microdomains, cells, neurite growth, compartment electrophysiology, synapses, plasticity, glia, extracellular fields, NumiBrain regional computation, NumanX body physics, and closed-loop biological-computing experiments.

The production runtime is GPU-resident and Metal-first. The repository is being built as a Swift 6 package with deterministic transactional execution, logical tissue tiles, adaptive biological fidelity, standardized neuroscience import, and explicit interfaces for NumiLab, NumiBrain, NumanX, and multielectrode-array systems.

## Status

Active development. The architecture, runtime, biology modules, importers, integration layer, command-line tools, and technical documentation are committed directly to `main` in coherent implementation stages.
